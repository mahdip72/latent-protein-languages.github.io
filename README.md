# Latent Protein Languages Project Page

Project page for *Learning Latent Protein Languages for Autoregressive Generation*.

Live site: https://mahdip72.github.io/latent-protein-languages.github.io/

The manuscript has been submitted to arXiv. After its public identifier is assigned, replace both paper placeholders in `index.html` with the arXiv abstract-page link and add the identifier to the BibTeX entry.

The site is static HTML, CSS, and JavaScript. To preview locally, run `python -m http.server 8765` from this directory.
